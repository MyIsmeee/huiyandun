# 模型卡：moge2-vits（C-CV-07）

| 项 | 内容 |
|---|---|
| 版本 | `moge2-vits-normal@e50ffda4+hyd.1`（未修改上游权重） |
| 用途 | 摄像头自动标定：单帧画面 → 度量点云与法向 → 拟合地面 → 建议安装高度、俯角、视角（`vision_engine/monocular.py`）。只对按安装参数估算地面映射的摄像头运行，启动后约 20 s 一次、此后每 10 min 一次；不检测、不区分人员，点云只在内存中、不持久化（G-04） |
| 上游 | Microsoft MoGe-2 ViT-S（带法向头），作者 Ruicheng Wang；ONNX 为作者发布的 `Ruicheng/moge-2-vits-normal-onnx`（提交 `e50ffda`，`model.onnx`） |
| 许可证 | MIT（同一作者的 PyTorch 权重 `Ruicheng/moge-2-vits-normal` 模型卡标注；代码仓库 microsoft/MoGe 为 MIT，其中 DINOv2 部分为 Apache-2.0） |
| 训练数据 | 上游论文所列合成与真实数据集（DINOv2 ViT-S/14 为骨干） |
| 导出精度 | FP32；输入 `image` 为 0～1 的 RGB（模型内部归一化）、`num_tokens` 为视觉词元数；输出仿射点图、法向、有效掩码与度量尺度。焦距、深度偏移的恢复不在 ONNX 图内，由 `monocular.py` 按官方 `infer()` 实现 |
| 目标平台 | ONNX Runtime：CUDA EP 与 CPU EP |

## 评测指标

| 指标 | 值 | 来源 |
|---|---|---|
| 单次推理（CPU，640×360 输入，1800 词元） | 约 1.2～2 s；一次估计含 4 次推理，约 8 s | 本地实测 |
| cam-05（室内办公室，俯拍广角）四种输入设置 | 高度 1.47～1.99 m（中位 1.69 m，720p 输入 1.79 m），俯角 −8.8°～−11.2°，视角 73.7°～75.5° | 本地实测；按门框高度目测验算约 1.8～1.9 m |
| 召回 / 误差分布 | 未评测 | 尚无带实测安装参数的摄像头数据 |

## 限制

- 单帧的度量尺度波动最大：画面中有大片桌面时按桌高 0.75 m 校正，否则沿用模型尺度，高度误差可达 ±25%
- 看不到足够地面（如对着墙、地面被完全遮挡）时不给建议
- 地面映射不含侧倾；侧倾超过数度时只提示
- 结果是建议值：由管理员在摄像头设置中填入后保存才生效，仍建议实地测量
