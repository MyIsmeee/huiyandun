# 模型卡：stgcnpp-ntu60-2d（C-CV-07）

| 项 | 内容 |
|---|---|
| 版本 | `stgcnpp-ntu60-2d@86e1e77a.cd11a691+hyd.1`（未修改上游权重，只把 joint、bone 两路合成一个 ONNX） |
| 用途 | 骨骼动作分类，复核跌倒与打架（`services/vision-engine/src/vision_engine/action.py`）。只输入 COCO 17 关键点序列，不看画面、不区分身份（G-04）。与骨骼几何规则联合判定，见 `behavior.py` 模块说明 |
| 上游 | OpenMMLab mmaction2 的 STGCN++（`configs/skeleton/stgcnpp`），NTU RGB+D 60 X-Sub、二维关键点（HRNet 提取）。权重为 `stgcnpp_8xb16-joint-u100-80e_ntu60-xsub-keypoint-2d_20221228-86e1e77a.pth` 与同目录的 bone 路 `…-cd11a691.pth`；模型代码固定在 mmaction2 v1.2.0（`4d6c9347`） |
| 许可证 | Apache-2.0（代码与权重） |
| 训练数据 | NTU RGB+D 60：数据集只许非商业的学术研究使用。用在商业产品前须另行评估，或换用自有数据重新训练分类头 |
| 转换 | `make fetch-models` 核对 joint 权重哈希后，由 `tools/dev/export_stgcnpp.py` 在 uv 临时环境中以 PyTorch 2.8.0 CPU 导出（opset 17）。bone 权重由脚本按固定哈希下载；依赖锁定在同名 `.lock`；导出可复现，两次导出哈希一致，不进入运行镜像 |
| 导出精度 | FP32。输入 `N×2×100×17×3`：2 人、100 帧、(x, y, 置信度)，坐标按 mmaction2 的 PreNormalize2D 归一化。输出 `N×60`，为两路 softmax 概率 1:1 平均 |
| 目标平台 | ONNX Runtime：CUDA EP（单独显存上限 256 MiB，`runtime.ACTION_MEM_MB`）与 CPU EP |
| 输入帧率 | 每路摄像头每 1 s 推理一次。每次覆盖在场每人的单人片段，以及伸手可及的每对人的双人片段，每批至多 4 个片段 |

## 预处理适配

- **时间**：NTU 是 30 帧/秒，本系统约 5 帧/秒。取近 3.3 s 的样本，按时间线性插值到 100 帧。原流程不足 100 帧时首尾循环，会把一次跌倒拉成好几个周期。
- **尺度与位置**：NTU 里的人约占 1080p 画面 600 像素高，且居中；监控画面里的人小、位置偏。按窗口内人体尺寸的 90 分位缩放到 650 像素，以髋部中位位置居中。整个窗口共用一套变换，倒下时的位移得以保留。
- **骨骼完整度**：窗口内至少 60% 的帧要有不少于 8 个可见关键点，否则不推理。残缺骨骼会让模型输出无意义的极端值（实测出现过恰好 0.50 和 1.00 的输出）。

## 门限（`behavior.py`）

| 门限 | 取值 | 依据 |
|---|---|---|
| 规则疑似 + 模型 → 确认跌倒 | 跌倒概率 ≥ 0.6（近 6 s 峰值） | 真实跌倒 0.65～0.95，非跌倒片段最高 0.58 |
| 只有模型 → 疑似跌倒 | ≥ 0.65 | 同上；只在控制台提示，不进入物理告警 |
| 两人贴近 + 模型 → 确认打架 | 打人、踢人、推人三类之和 ≥ 0.7，近 3.5 s 内至少 2 次；同期须有至少 2 帧满足几何条件（双方手腕快速运动、两人没有一起移动），且两人髋部距离不低于 0.6 倍躯干长 | 人流中最高 0.42；只靠模型时坐着聊天、并排站着也会被认作推人，同一人被拆成两条重叠轨迹时会被当成推搡（现场实测）；尚无正样本，门限未经召回校准 |

## 限制

- 训练数据是室内、正对 Kinect、单次动作清晰的表演，和俯拍、遮挡多的监控画面有领域差异。上面的门限只在本仓库的少量片段上核对过，需要用现场录制继续校准（`make explain-live` 录制骨骼，再用 `tools/dev/eval_behavior.py --action` 评测）。
- 跌倒概率只在"倒下的过程"中高，倒地之后静躺时会回落。所以模型只作提前确认的依据；没看到跌倒过程时，仍按原规则倒地不动满 8 s 确认。
- NTU 没有"走路""躺着"这类类别，日常走动多被认作"踉跄"。只用跌倒、打人、踢人、推人这几类，其余类别仅供诊断。
- 打架只看两人之间：多人群殴时按两两配对判定；距离太远（超过约 2.5 倍躯干长）不配对。
