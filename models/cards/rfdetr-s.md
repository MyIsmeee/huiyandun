# 模型卡：rfdetr-s（C-CV-07）

| 项 | 内容 |
|---|---|
| 版本 | `rfdetr-s@1.4.2+hyd.1`（未修改上游权重） |
| 用途 | 车辆检测：自行车、轿车、摩托车、公交、货车，供实时感知大屏（spec.md FR-101、FR-102）；人员框与 rtmo-s 的检出合并，骨骼由 rtmo-s 提供（#287）。模型可检出 COCO 80 类，vision-engine 只取上述 5 类与人员 |
| 上游 | Roboflow RF-DETR 1.4.2 Small；ONNX 为 rtmlib 内置 `RFDETR` 引用的导出（Hugging Face `saifkhichi96/opendetect`，提交 `e9a01bb`） |
| 许可证 | Apache-2.0（RF-DETR Nano / Small / Medium / Large 权重；XL 及以上许可证不同，不得使用） |
| 训练数据 | COCO（上游公开数据集，使用条款见其官网） |
| 导出精度 | FP32；输入 `1×3×512×512`；输出 300 个查询的归一化框与 91 维分类 logits（第 0 维为背景），无需 NMS |
| 目标平台 | ONNX Runtime：CUDA EP（D0：sm_120；开发机：sm_86）与 CPU EP（D0-min） |
| 输入帧率 | 与 rtmo-s 相同，固定 5 FPS，对运动门控区域推理 |

## 评测指标

| 指标 | 值 | 来源 |
|---|---|---|
| COCO val2017 AP | 53.0（Small） | 上游报告 |
| 单帧耗时（CPU，6 核，1280×720 输入） | 约 400 ms | 本地实测 |
| 演示素材抽帧检出 | cam-01、cam-02 共 14 帧：摩托车、轿车、自行车均检出，置信度 0.7～0.9 | 本地实测 |
| 人员框（#286，10 段调试素材 4169 帧） | crowd-1（1080p，每帧约 15 人）身高不足画面 15% 的行人 rtmo-s 多数检不出，本模型能检出；被家具遮挡的倒地者本模型会漏、rtmo-s 能检出 | 本地实测，与 rtmo-s 逐帧对照并人工核对抽样帧 |
| 召回 / 精确率 / 每路每小时误报 | 未评测 | 尚无标注评测集 |

## 限制

- 只到类别，不识别车牌，不输出任何身份信息（G-04）
- 运动门控下，从未运动过的静止车辆不会被检出；进入画面或开始移动后检出并持续跟踪
- 骑车人被检为人员，其车被检为自行车或摩托车，场景中两者叠加显示
- 置信度 0.3～0.5 的框只用于延续已有轨迹：车辆局部偶尔被当作另一辆车（moto-fire-1）
