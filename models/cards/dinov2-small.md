# 模型卡：dinov2-small（C-CV-07）

| 项 | 内容 |
|---|---|
| 版本 | `dinov2-small@8b1f705a+hyd.1`（未修改上游权重） |
| 用途 | 画面可信度：整帧画面嵌入序列判定画面重放（spec.md FR-302，REUSE-23）。只取整帧的 CLS 嵌入，不检测、不区分人员；嵌入只在内存中保留 190 s，不持久化（G-04） |
| 上游 | Meta DINOv2 ViT-S/14（`facebook/dinov2-small`）；ONNX 为 Hugging Face `onnx-community/dinov2-small` 的导出（提交 `8b1f705`，`onnx/model.onnx`） |
| 许可证 | Apache-2.0 |
| 训练数据 | LVD-142M（上游自监督预训练，无标注） |
| 导出精度 | FP32；输入 `1×3×224×224`（整帧缩放、不裁剪，ImageNet 均值方差归一化）；输出 `last_hidden_state` `1×257×384`，取第 0 个 token |
| 目标平台 | ONNX Runtime：CUDA EP（D0：sm_120；开发机：sm_86）与 CPU EP（D0-min） |
| 输入帧率 | 固定 5 FPS，与检测相同，每个检测帧取一次嵌入（C-CV-08） |

## 评测指标

| 指标 | 值 | 来源 |
|---|---|---|
| 单帧耗时（CPU，6 核，1280×720 输入） | 约 60 ms | 本地实测 |
| 重放判定每次比对耗时（CPU，每路每秒 1 次） | 约 25 ms | 本地实测 |
| 演示素材 cam-01、cam-02 各连续两轮循环（519 s、578 s） | 重放误报 0；非重放的最高相关系数 0.25 | 本地实测 |
| 模拟重放（素材重新编码、采样时刻错开 0.1 s，把 60 s 前的片段重放 40 s，起点每 10 s 取一次） | 64 次全部检出，匹配时刻误差 ≤ 0.4 s；判定在重放开始后 12～22 s（重放片段含剪接时较慢） | 本地实测 |
| 召回 / 精确率 / 每路每小时误报 | 未评测 | 尚无现场摄像头数据 |

## 限制

- 静止画面的重放不判定（去掉均值后只剩噪声），由冻结判定覆盖
- 画面切换（如素材剪接、灯光骤变）后 10 s 内不判定重放
- 同一场景不同时刻的整帧嵌入相似度高达 0.97，不能以嵌入本身相似判定重放；判定比较的是嵌入随时间的变化（`vision_engine/integrity.py`）
